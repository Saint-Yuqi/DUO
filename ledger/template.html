Protocols

How to maintain

  1. Edit ledger/runs.yaml (one entry per run; set status: superseded instead of deleting). New head version → ledger/variants.yaml. New external number → ledger/external.yaml with source + snapshot date. Table layout → ledger/tables.yaml.
  2. Finished evaluation → python eval/robotwin/summarize.py <run_root> --run-id <id> prints the results: block and writes the per-task file.
  3. python ledger/build.py regenerates docs/index.html, docs/ledger.json and paper/tables/*.tex; then bash scripts/push_remotes.sh pushes to GitHub and Codeup. The page is also republished as a claude.ai artifact from docs/artifact.html.
  4. Overleaf: copy paper/tables/<id>.tex over the table file in the Overleaf project (scripts/sync_paper.sh shows the diff). Numbers flow YAML → page → paper, never the other way.
