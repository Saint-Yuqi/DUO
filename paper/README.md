# paper — Duo-WAM (CVPR 2026 template) tables

The manuscript lives in Overleaf; the paper owner mirrors it to https://github.com/pikonguwu/Duo-WAM (local clone `~/Duo-WAM`).
`paper/tables/*.tex` are generated by `ledger/build.py` from the ledger and have the same shape as the Overleaf `table/*.tex`
files, so a table can be replaced wholesale. `bash scripts/sync_paper.sh` pulls the mirror and prints the diff per table.

Known label problems in the Overleaf draft (2026-10-08), all resolved by the ledger's sources:
* `robotwin_main`: "SmolVLA 29.78/2.76" is **our** SmolVLA run, not a leaderboard entry; "Flower(duo dit(from pretrained))" = run
  `flower_duodit_clean2500`; "Flower(+ROPE duo dit)" = run `flower_customduodit_rope_clean2500` (custom scratch head + RoPE).
* `action_head_transfer`: the π0.5 "Native overall" column is empty although the leaderboard π0.5 (58.35) is the only native number we have;
  no same-recipe plain π0.5 was trained.
* `openwam_flower_duo_dit`: a single-stream "Flower" row does not exist — the run once called "FLOWER baseline" is the FlowBlock Duo head.
* "LightWAM" appears in five tables, is undefined in the text and absent from `main.bib`.
